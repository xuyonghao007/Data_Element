📋 研一新生入学 Checklist

系统化完成入学准备，为科研之路打下坚实基础

建议在入学后2周内完成以下所有项目

已完成: 0 / 0 项 (0%)

第一部分：软件与工具安装

第1-3天完成
  • 安装 Stata (推荐SE/MP版本)

    用于计量经济学分析和实证研究。可从学校图书馆获取正版授权或使用学生版

    必需
  • 安装 Zotero 文献管理软件

    免费开源的文献管理工具，支持浏览器插件一键保存文献，自动生成参考文献

    必需
  • 安装 Python 环境 (Anaconda)

    用于数据清洗、文本分析、机器学习等高级方法。建议安装Jupyter Notebook

    推荐
  • 配置 LaTeX 编辑环境 (Overleaf/TeXstudio)

    学术论文写作标准工具，期刊投稿必备。建议先熟悉Overleaf在线版

    推荐
  • 申请数据库访问权限

    CSMAR、WIND、CNRD等金融数据库的校园网访问权限，以及学校VPN设置

    必需
  • 注册 Google Scholar / Web of Science 账号

    设置文献 alerts，关注领域内重要学者的最新发表

    建议

第二部分：基础知识储备

第1-2周完成
  • 阅读《学术研究导航说明》

    了解金融学研究全景图、核心能力要求、时间规划路径 → 查看详情

    必需
  • 浏览金融学各子领域介绍

    了解资产定价、公司金融、行为金融等10+细分领域的研究内容和方法特点 → 探索领域地图

    必需
  • 精读3-5篇本领域综述性论文

    选择感兴趣的方向，阅读近3年发表的综述文章，建立领域认知框架

    必需
  • 复习计量经济学基础

    回顾OLS、假设检验、面板数据基础等内容。参考教材：《计量经济学及Stata应用》- 陈强

    重要
  • 了解学术期刊分级体系

    熟悉国内(经济研究、管理世界等)和国际(JF/JFE/RFS等)顶刊的定位和偏好 → 查看期刊列表

    重要

第三部分：核心技能入门

第2-4周开始
  • 完成 Stata 入门教程

    掌握数据导入导出、描述性统计、基本回归操作。建议跟随视频教程实操一遍

    必需
  • 学习 Zotero 高效使用技巧

    包括：浏览器插件使用、标签分类、笔记功能、Word/LaTeX集成、团队共享库

    必需
  • 练习复现一篇经典论文

    选择有公开代码和数据的简单论文（如JFE Top3），尝试完整复现其结果 → 查看方法指南

    重要
  • 学习文献检索策略

    掌握关键词组合、引文追踪、数据库筛选等高效检索方法 → 查看详细指南

    重要
  • 了解 AI 辅助科研工具

    学习如何使用 ChatGPT/Claude 等工具辅助文献解读、代码生成、写作润色 → 查看AI指南

    建议

第四部分：人际网络与规划

持续进行
  • 与导师进行首次深入交流

    讨论研究方向兴趣、了解课题组风格、明确第一学期期望目标

    必需
  • 加入/创建学术讨论小组

    寻找同方向的同学组成2-3人学习小组，定期讨论文献和研究想法

    推荐
  • 参加组会并积极旁听

    即使不汇报也要参加，了解学术报告规范、学习师兄师姐的研究思路

    必需
  • 制定个人研一时间表

    基于全年规划模板，结合个人情况制定详细的月度和周度计划 → 查看时间规划

    必需
  • 完成能力自我评估

    诊断现有技能水平，识别优势与短板，制定针对性提升计划 → 立即评估

    推荐

新生温馨提示

  • 不要急于求成：科研是长跑，前几个月的重点是打基础而非出成果
  • 保持好奇心：多问"为什么"，多和导师同学交流，不要害怕暴露无知
  • 建立规律作息：固定时间阅读文献、写代码、锻炼身体，形成良性循环
  • 善用AI工具：让ChatGPT成为你的24小时助教，但记住它只是辅助不能替代思考
  • 记录一切：用Notion/Obsidian记录每日学习心得、文献笔记、灵感闪念
