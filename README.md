# 金融学研一科研培训体系

## 项目简介

本项目为金融学研究生一年级学生设计的完整学术科研培训体系，包含流程、资源、网页和智能体辅助学习系统。通过系统化的培训，帮助新生快速掌握学术研究的核心技能和方法。

## 核心功能

### 1. 领域知识图谱
- 覆盖金融学10个核心子领域
- 每个领域提供研究前沿、经典文献和研究方法
- 引导学生快速了解各领域的研究现状

### 2. 核心技能训练
- **研究方法**：实证研究方法、计量模型、识别策略
- **数据分析**：Stata、Python等工具使用
- **写作能力**：论文结构、学术写作技巧、AI辅助写作

### 3. AI辅助工具
- 论文初稿写作提示词设计
- 基于Few-shot学习的写作指导
- 智能文献阅读和分析工具

### 4. 顶刊文献参考
- 整合顶级金融学期刊列表
- 提供文献检索和阅读建议
- 帮助学生建立高质量的文献库

## 技术特点

- **响应式设计**：适配不同设备屏幕
- **交互式界面**：提供友好的用户体验
- **模块化结构**：便于后续扩展和更新
- **AI辅助功能**：集成现代AI技术提升学习效率

## 使用指南

1. 从主页面 `index.html` 开始，了解整体培训体系
2. 根据自身需求选择相应模块进行学习
3. 利用AI工具辅助写作和研究
4. 参考顶刊文献列表开展文献综述

## 目标受众

- 金融学一年级研究生
- 对金融学术研究感兴趣的高年级本科生
- 希望提升科研能力的青年教师和研究人员

- 建立系统化的知识体系和研究框架
