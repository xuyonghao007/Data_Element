研一推荐学习路径

第1-2周：入学适应期 🎯

完成入学清单 → 能力自评 → 安装软件(Stata/Zotero) → 浏览领域概览

第3-6周：基础建设期 📚

精读5篇综述 → 学习计量基础 → 建立文献管理系统 → 参加组会旁听

第7-12周：能力提升期 🔧

完成第一篇文献综述 → 复现经典论文 → 学习数据清洗 → 撰写研究计划初稿

第13-18周：实践应用期 ✍️

确定研究方向 → 完成开题报告 → 开始数据处理 → 准备寒假研究计划

寒假：深化突破期 💡

深入研究计划 → 数据收集整理 → 初步实证分析 → 形成Working Paper框架

第二学期：成果输出期 🚀

完善论文初稿 → 投稿或会议汇报 → 准备PhD申请材料 → 开启独立研究
