提示词使用指南

核心写作思路

1. 写作要点凝练

将每一段、每一句的写作要点凝练为简洁的提示词，帮助AI准确理解你的写作需求：

  • 摘要：问题提出 → 数据方法 → 主要发现 → 机制解释 → 研究贡献
  • 引言：现象引入 → 核心问题 → 研究重要性 → 文献缺口 → 研究设计 → 主要发现 → 研究贡献
  • 文献综述：分类梳理 → 批判性分析 → 理论框架 → 研究假说
  • 研究设计：数据来源 → 样本选择 → 变量定义 → 实证模型 → 识别策略
  • 实证结果：基准结果 → 机制分析 → 异质性分析 → 稳健性检验 → 经济意义

2. Few-shot算法思想

Few-shot学习是一种让AI通过少量示例快速学习新任务的方法。在学术写作中，你可以：

  • 提供1-3个优秀的写作范例，让AI学习其风格和结构
  • 明确指出范例中的亮点和值得借鉴的地方
  • 要求AI在生成内容时参考范例的写作方式

3. 优秀写作范例

摘要写作范例

We develop a return variance decomposition model to separate the role of different types of information and noise in stock price movements. Overall, 31% of the return variance is from noise, 37% from public firm-specific information, 24% from private firm-specific information, and 8% from market-wide information. Since the mid-1990s, there has been a dramatic decline in noise and an increase in firm-specific information, consistent with increasing market efficiency.
