📊 B1: 计量经济学基础与Stata入门

从OLS到面板数据，掌握金融实证研究的核心工具

必须掌握的核心概念

OLS回归基础

最小二乘法是所有计量方法的基石。需要理解：
• 古典假设（线性性、无完全共线性、条件零均值、同方差、无自相关、正态性）
• 系数解释（边际效应）、R²含义、t检验和F检验
• 违背假设时的后果及初步诊断方法

面板数据模型

面板数据是金融研究中最常用的数据结构。
• 固定效应(FE) vs 随机效应(RE)：Hausman检验选择
• 双向固定效应：控制个体异质性和时间趋势
• 聚类标准误(Clustered SE)：处理组内相关性

内生性问题

内生性是实证研究的核心挑战。
• 三大来源：遗漏变量偏差(OVB)、双向因果、测量误差
• 后果：OLS估计量不一致且有偏
• 解决思路：寻找合适的识别策略(详见B2)

假设检验与推断

正确理解统计显著性。
• p值 ≠ 重要性！区分统计显著 vs 经济显著
• 多重比较问题(Bonferroni校正)
• 置信区间的正确解读和应用

Stata核心操作速查

数据导入与基本操作

* 导入数据（支持Excel/CSV/Stata格式） import excel "data.xlsx", firstrow clear use "data.dta", clear * 查看数据概览 describe // 变量信息 summarize // 描述性统计 tabulate industry // 分类变量频数 browse // 浏览数据 * 数据处理 gen ln_assets = log(total_assets) // 生成新变量 replace missing = 0 if missing(missing) // 替换缺失值 drop if year < 2010 // 删除观测 keep id year roa leverage esg // 保留指定变量 * 数据合并（面板数据常用） merge 1:1 id year using "control_vars.dta"

回归分析核心命令

* 基准OLS回归 regress y x1 x2 x3 controls, robust * 固定效应面板回归（最常用！） xtset id year // 声明面板结构 xtreg y x1 x2 x3 controls i.year, fe cluster(id) * 双向固定效应（个体+时间） reghdfe y x1 x2 x3 controls, absorb(id year) vce(cluster id) // 注：reghdfe是外部命令，需先安装：ssc install reghdfe * 分组回归（异质性分析） bysort group: regress y x1 x2 controls // 或使用esttab批量输出结果 * 输出回归表格（推荐estout系列命令） eststo: xtreg y x1 controls, fe eststo: xtreg y x1 x2 controls, fe esttab est1 est2, keep(x1 x2) stats(N r2) star(* 0.1 ** 0.05 *** 0.01)

诊断检验

* 多重共线性检验 vif // VIF > 10 表示严重多重共线性 * 异方差检验 hettest // Breusch-Pagan检验 * Hausman检验（FE vs RE选择） * 描述性统计表输出 asdoc sum y x1 x2 controls, save(mytable.doc) replace

推荐学习路径

1
第1周：环境搭建 + 数据导入导出

安装Stata SE/MP，熟悉界面操作，练习导入不同格式的数据集，掌握describe/summarize/tabulate等基本命令

2
第2周：OLS回归完整流程

从数据清理到运行回归再到输出结果表。重点理解系数含义、标准误、t统计量、p值、R²等核心概念

3
第3-4周：面板数据深入

学习xtset/xtreg命令，理解FE vs RE的区别和Hausman检验，掌握聚类标准误的重要性

4
第5-6周：复现经典论文

找一篇有公开数据和代码的简单论文（如JFE Top3），尝试完整复现其基准回归结果。这是最好的学习方法！
