CSMAR / WIND / CNRDS — 从原始数据到干净分析样本的全流程

主流金融数据库一览

CSMAR (国泰安)

国内最常用的学术数据库。覆盖股票、基金、债券、衍生品、经济、行业等多个子库。高校通常有校园网授权，是研究生必备的数据源。

国内首选 · 高校授权

WIND (万得)

金融机构广泛使用的终端数据库。数据更新快、指标丰富，尤其擅长实时行情和市场数据。部分功能需单独购买权限。

机构常用 · 实时性强

CNRDS (中国研究数据服务平台)

专注于特色主题数据，如文本数据(年报MD&A)、专利数据、ESG评级、分析师报告等。独特数据源，适合做创新性研究。

特色数据 · 创新研究

其他补充数据源

• CEIC：宏观经济数据
• RESSET：锐思金融研究数据库
• CNRDS：文本与另类数据
• 手工收集：网站爬取/年报整理

数据清洗标准七步流程

Step 1: 数据获取与导入

从数据库下载原始数据，检查字段名称和数据类型是否正确。注意日期格式统一（建议转为数值型YYYYMMDD）。

import excel "raw_data.xlsx", firstrow clear describe // 检查变量数量和类型

Step 2: 样本筛选

根据研究设计确定样本范围：时间区间、行业分类、市场板块(ST/*ST剔除)、特殊样本(金融业/IPO当年)处理。

* 时间筛选 keep if year >= 2010 & year <= 2023 * 剔除特殊样本 drop if industry == "J" // 金融业 drop if substr(stkcd,1,1) == "2" | substr(stkcd,1,3) == "688" // 创业板/科创板视需求 * ST/*ST标记 gen st_flag = (substr(name,1,2) == "ST" | substr(name,1,3) == "*ST") drop if st_flag == 1

Step 3: 变量构造

根据文献中的定义构造核心变量。注意单位统一（万元vs亿元）、取对数处理极端值、行业年度调整等。

* 核心被解释变量：融资成本 gen cost_debt = interest_expense / total_debt // 利息支出/总负债 * 取对数 gen ln_size = log(total_assets) * 行业-年度均值调整 bysort industry year: egen mean_roa = mean(roa) gen roa_adj = roa - mean_roa

Step 4: 缺失值处理

检查各变量的缺失情况，决定删除还是插补。关键原则：记录每一步处理的原因和影响样本量。

注意事项

不要盲目删除缺失值！应先分析缺失原因（MCAR/MAR/MNAR）。对于少量随机缺失可直接删除；对于系统性缺失需谨慎处理并在文中说明。

* 查看缺失情况 missum summarize // 需安装：ssc install missum * 删除关键变量缺失的观测 drop if missing(y) | missing(core_x) * 报告最终样本量 count di "Final sample size: " r(N)

Step 5: 异常值处理

常用的异常值处理方法：缩尾(Winsorize)和截尾(Trim)。一般对连续变量在1%和99%分位数进行处理。

* 安装winsor2命令（强烈推荐） ssc install winsor2 * 对主要变量进行1%缩尾处理 winsor2 y x1 x2 x3 controls, cut(1 99) suffix(_w) label * 或者手动实现 foreach var of varlist y x1 x2 { quietly summarize `var', detail replace `var' = r(p1) if `var' < r(p1) & !missing(`var') replace `var' = r(p99) if `var' > r(p99) & !missing(`var') }

Step 6: 描述性统计输出

生成标准的描述性统计表，包括观测数、均值、标准差、最小值、最大值。这是论文Table 1的基础。

* 方法1：asdoc输出到Word asdoc sum y x1 x2 x3 controls, save(descriptive_stats.doc) title(Table 1 Descriptive Statistics) replace * 方法2：esttab输出（更美观） estpost summarize y x1 x2 x3 controls esttab using "table1.rtf", cells("count mean sd min max") label noobs replace

Step 7: 相关性矩阵与VIF检验

检查变量间的相关关系（避免高度相关的变量同时进入模型）和多重共线性问题（VIF>10需关注）。

* 相关系数矩阵 pwcorr y x1 x2 x3 controls, sig star(0.05) * VIF检验 regress y x1 x2 x3 controls vif // VIF > 10 表示严重多重共线性

数据清洗最佳实践

Do's ✅
  • 每一步都保存中间版本（data_step1.dta, data_step2.dta...），方便回溯
  • 写清晰的注释说明每步操作的目的
  • 记录样本筛选前后的观测数变化，在论文中报告
  • 异常值处理方法要在正文中说明并做稳健性检验
  • 使用do文件而非手动操作，保证可重复性
Don'ts ❌
  • 不要在原始数据上直接修改（始终保留原始备份）
  • 不要为了得到"好结果"而选择性删减样本
  • 不要忽略数据的时间属性（面板数据要注意排序和声明）
  • 不要忘记汇报最终的样本量和筛选过程
