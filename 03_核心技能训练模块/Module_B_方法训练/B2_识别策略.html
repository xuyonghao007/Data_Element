双重差分法 (DID)

⭐ 最常用 · 政策评估首选

核心思想：通过对比"处理组"和"对照组"在政策实施前后的差异变化，来识别政策的因果效应。

关键假设：平行趋势假设 (Parallel Trends)

如果没有政策干预，处理组和对照组的变化趋势应该是一致的。

适用场景：

  • 某项法规/政策只在部分地区或部分企业实施（准自然实验）
  • 可以明确区分处理组和对照组
  • 有政策实施前后的多期数据

典型应用：

  • 注册制改革对IPO定价效率的影响
  • 碳交易市场对企业碳排放的影响
  • 沪港通开通对A股市场的影响

Stata实现要点：

  • 平行趋势检验（事件研究法 Event Study）
  • 多期DID (Staggered DID) 注意处理TWFE偏差
  • 安慰剂检验 (Placebo Test)、排除其他解释

工具变量法 (IV)

解决内生性的经典方法

核心思想：找到一个与内生解释变量相关但与误差项无关的工具变量(Z)，用Z的变异来识别X对Y的因果效应。

IV的两个核心条件

① 相关性 (Relevance)：Cov(Z,X) ≠ 0 → 工具变量必须与内生解释变量强相关
② 外生性 (Exclusion)：Cov(Z,ε) = 0 → 工具变量只能通过X影响Y，不能直接影响Y

常见IV来源：

  • 法律/制度作为IV：如反收购条款指数(CFC)、投资者保护法律
  • 地理/历史因素：如到沿海距离、历史上的移民比例
  • 行业均值/滞后值：需谨慎论证外生性
  • Bartik/shift-share IV：近年热门构造方式

检验步骤：

  • 第一阶段F统计量 > 10（弱工具变量检验）
  • 过度识别检验（Sargan/Hansen J检验，多IV时）
  • Durbin-Wu-Hausman检验（内生性检验）

断点回归 (RDD)

局部随机实验 · 高可信度

核心思想：当某个连续变量存在临界值(cutoff)，且个体在该临界值两侧的分配近似随机时，可以利用断点附近的样本进行因果推断。

核心假设：连续性假设

除了处理变量在断点处跳跃外，其他所有变量在断点处都是连续平滑的。

类型：

  • Sharp RDD：处理概率从0跳到1（如：高考分数线以上录取）
  • Fuzzy RDD：处理概率在断点处跳跃但非0→1（如：达到年龄可申请但非强制）

典型应用：

  • 融资融券标的是否纳入对股价效率的影响（以某个指标阈值为断点）
  • 信用评级门槛对企业融资成本的影响
  • 税收优惠政策起征点的效果评估

关键操作：

  • 带宽(bandwidth)选择：最优带宽 vs 不同带宽稳健性检验
  • 操纵检验 (Manipulation Test)：检查个体是否操纵驱动变量
  • 协变量平衡检验：断点两侧协变量应无系统性差异

倾向得分匹配 (PSM)

构建反事实对照组

核心思想：基于可观测特征计算每个个体的"倾向得分"(即被处理的概率)，然后为处理组的每个个体匹配得分相近的对照组成员，从而构建反事实(counterfactual)。

匹配方法：

  • 最近邻匹配 (Nearest Neighbor)：1:1 或 1:k 匹配
  • 核匹配 (Kernel Matching)：利用所有对照组加权
  • 半径匹配 (Radius Matching)：设定得分容忍范围

注意事项：

  • PSM只能解决基于可观测变量的选择偏差，无法处理不可观测的内生性
  • 常与DID结合使用：PSM-DID（先匹配再双重差分）
  • 必须进行平衡性检验：匹配后处理组和对照组特征应无显著差异

局限性与替代方案：

  • 如果怀疑不可观测因素影响选择，考虑用IV或RDD
  • 近年来合成控制法(Synthetic Control Method)在政策评估中越来越流行

四种方法对比速查表

方法 核心优势 关键假设 主要风险
DID 直观易懂，政策评估首选 平行趋势 趋势不平行则失效
IV 适用范围广，灵活性强 工具变量有效性 弱工具变量导致偏误
RDD 局部随机化，可信度高 连续性 + 无操纵 样本量损失大
PSM 缓解选择偏差 条件独立性(只基于可观测) 无法处理不可观测内生性
