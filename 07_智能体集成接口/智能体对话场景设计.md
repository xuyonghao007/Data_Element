# AI智能体 (FinResearch-Buddy) 集成接口文档

## 🤖 智能体概述

### 定位
**FinResearch-Buddy** 是一款专为金融学研一学生设计的**科研陪伴型AI导师**，旨在提供全流程的学术研究辅助。

### 核心特性
- 🎓 **角色定位**：经验丰富的博士生学长/学姐
- 💬 **语调风格**：鼓励性 + 专业性 + 耐心
- 🎯 **能力边界**：不代写论文，只提供方法论指导和思路启发
- 🔒 **伦理准则**：引导学生独立思考，培养真正的科研能力

## 📦 功能模块设计

### Module 1: 文献助手 (Literature Assistant)

#### 功能描述
自动解读学术论文，生成结构化摘要，辅助文献理解与知识管理。

#### 输入/输出规格

```
输入:
  - 论文PDF文件
  - 或 论文题目/DOI/关键词
  
输出:
  ✅ 结构化10要素摘要（作者、时间、期刊、发现、理论、数据、变量、机制、贡献）
  ✅ PPT大纲（HTML格式，可直接演示）
  ✅ 与知识库中其他文献的关联分析
  ✅ 研究缺口识别建议
```

#### 调用示例
```python
# Python调用示例（伪代码）
response = finresearch_buddy.literature_assistant(
    input_type="pdf",
    file_path="./papers/example.pdf",
    output_format="structured_summary"
)
```

#### 对应Prompt模板
- `paper_summary_prompt.txt` - 10要素结构化总结
- `ppt_generation_prompt.txt` - 学术PPT生成

### Module 2: 方法顾问 (Methodology Consultant)

#### 功能描述
根据研究问题推荐合适的实证方法，生成代码框架，解决技术难题。

#### 输入/输出规格

```
输入:
  - 研究问题描述
  - 数据类型与来源
  - 变量列表（解释变量、被解释变量、控制变量）
  
输出:
  ✅ 推荐识别策略（DID/IV/RD/PSM等）及理由
  ✅ Stata/Python代码框架
  ✅ 内生性问题解决方案清单
  ✅ 稳健性检验建议
  ✅ 可能遇到的坑与注意事项
```

#### 方法选择决策树

```
研究问题类型判断：
├── 政策评估类 → DID / RD / 合成控制法
├── 因果推断类 → IV / RDD / 断点回归
├── 相关性研究 → 面板固定效应 / OLS聚类标准误
└── 预测建模类 → ML方法（随机森林/XGBoost/LSTM）

数据特征考虑：
├── 截面数据 → 聚类稳健标准误 / Bootstrap
├── 面板数据 → 固定效应 / 随机效应检验
├── 时间序列 → 单位根检验 / 协整关系
└── 高频数据 → 微观结构模型 / 事件研究
```

### Module 3: 写作教练 (Writing Coach)

#### 功能描述
对学术写作进行润色、优化和规范化指导。

#### 输入/输出规格

```
输入:
  - 初稿段落或章节
  - 当前写作阶段（引言/文献综述/实证/结论）
  - 目标期刊（可选）
  
输出:
  ✅ 语言润色建议（学术表达、句式多样性）
  ✅ 逻辑结构优化（段落组织、论证链条）
  ✅ 学术表达规范化（术语使用、引用格式）
  ✅ 常见错误检查（语法、格式、逻辑漏洞）
  ✅ 期刊风格适配建议
```

#### 写作阶段检查清单

**引言部分：**
- [ ] 研究问题是否清晰具体？
- [ ] 是否说明了现实意义和理论意义？
- [ ] 是否明确指出了研究缺口？
- [ ] 全文结构是否有预告？

**文献综述部分：**
- [ ] 是否按主题分组而非简单罗列？
- [ ] 每段是否有明确的主题句？
- [ ] 是否有批判性评价？
- [ ] 是否指出了与本研究的关联？

**实证部分：**
- [ ] 数据来源是否详细说明？
- [ ] 变量定义是否清晰可操作？
- [ ] 模型设定是否有理论依据？
- [ ] 结果解读是否区分统计显著性和经济显著性？

### Module 4: Idea激发器 (Idea Generator)

#### 功能描述
帮助学生从0到1产生可行的研究想法，并进行初步可行性评估。

#### 输入/输出规格

```
输入:
  - 感兴趣的研究领域（如：公司金融-ESG）
  - 已读文献列表（可选）
  - 现实观察/政策变化/新闻事件（可选）
  
输出:
  ✅ 5-10个潜在研究想法（按创新性排序）
  ✅ 每个想法的可行性评分（1-5星）
  ✅ 创新点与贡献预判
  ✅ 所需数据与方法建议
  ✅ 潜在风险与挑战预警
```

#### Idea质量评估框架

| 维度 | 权重 | 评估标准 |
|------|------|----------|
| **新颖性** | 30% | 是否填补了现有研究的空白？ |
| **重要性** | 25% | 研究问题是否有足够的理论与现实意义？ |
| **可行性** | 25% | 数据是否可获得？方法是否可掌握？ |
| **贡献度** | 20% | 能否发表在目标级别的期刊？ |

#### 创意激发技巧

1. **问题转换法**：将其他领域的问题引入本领域
2. **方法移植法**：用新方法解决旧问题
3. **数据创新法**：利用独特的数据源（文本、图像、卫星）
4. **政策联动法**：结合最新政策变化寻找自然实验
5. **跨界融合法**：引入心理学/计算机/法学的视角

### Module 5: 进度管理器 (Progress Manager)

#### 功能描述
追踪学生学习进度，提供个性化的下一步行动建议。

#### 输入/输出规格

```
输入:
  - 当前所处阶段（入学/基础建设/能力提升/实践应用）
  - 已完成的任务列表
  - 设定的目标时间（如：研一结束前发表一篇）
  
输出:
  ✅ 下一步具体行动建议（按优先级排序）
  ✅ 时间风险评估（是否能按时完成）
  ✅ 学习路径动态调整建议
  ✅ 激励性反馈与里程碑提醒
  ✅ 资源推荐（匹配当前阶段的工具/课程/文献）
```

#### 阶段性里程碑定义

```
阶段1: 入学适应期 (第1-2周)
  └─ 里程碑: 完成软件安装 + 浏览领域概览 + 与导师首次交流

阶段2: 基础建设期 (第3-6周)
  └─ 里程碑: 精读5篇综述 + Stata入门 + 建立文献管理系统

阶段3: 能力提升期 (第7-12周)
  └─ 里程碑: 完成首篇文献综述 + 复现经典论文 + 撰写研究计划初稿

阶段4: 实践应用期 (第13-18周)
  └─ 里程碑: 确定研究方向 + 完成开题报告 + 开始数据处理

阶段5: 成果产出期 (寒假+第二学期)
  └─ 里程碑: 形成Working Paper框架 + 投稿或会议汇报
```

### 场景2: 文献阅读困惑

**用户输入**: "这篇JFE的文章我看不懂他们的识别策略"

**Agent回复**:
> "别担心，这很正常！让我帮你拆解一下...
> 
> 这篇文章用的是**双重差分法(DID)**，核心逻辑是：
> 
> 📊 **处理组 vs 对照组**：受政策影响的企业 vs 未受影响的企业
> ⏰ **前后对比**：比较政策实施前后的差异
> 🔍 **关键假设**：平行趋势假设（处理组和对照组在政策前趋势一致）
> 
> 我给你画个示意图帮你理解... [生成可视化图表]
> 
> 💡 **进阶建议**：
> - 如果你想深入学习DID方法，可以查看[Module_B方法训练](../03_核心技能训练模块/Module_B_方法训练/B2_识别策略.html)
> - 我这里有几篇讲DID方法的入门文章，需要推荐给你吗？"

### 场景3: 研究瓶颈突破

**用户输入**: "我的Idea被导师说没有创新性"

**Agent回复**:
> "这是科研过程中必经的阶段！💪 让我们一起客观分析...
> 
> **你的想法优势**：
> - 在X方面确实有一定的启发性
> - 结合了最新的Y政策背景，时效性好
> 
> **可能的改进方向**：
> 
> ✅ **找更独特的切入角度**：
>    - 比如：不只看政策的平均效果，而是关注异质性影响
>    - 或者：加入中介机制的分析（通过什么渠道产生影响？）
>    
> ✅ **加强机制的深度**：
>    - 现有的Z机制分析还可以更细致
>    - 可以尝试用不同的数据来验证同一机制
>    
> ✅ **考虑异质性分组**：
>    - 不同规模/行业/地区的企业可能有不同反应
>    - 这种异质性本身可能就是重要的研究发现
> 
> 📚 **案例参考**：
> 我这里有3篇类似的案例，看看他们是如何从"被拒"到"接收"的改进过程...
> 
> 要不要我们一起重新梳理一下你的研究故事？"

## ⚠️ 使用限制与伦理声明

### 我们承诺
- ✅ 不代写任何形式的学术论文
- ✅ 不提供可直接抄袭的内容
- ✅ 引导学生独立思考和原创
- ✅ 保护用户隐私和数据安全

### 用户须知
- ⚠️ AI生成内容仅供参考，最终判断需自行负责
- ⚠️ 学术诚信是底线，请合理使用AI辅助工具
- ⚠️ 建议将AI作为"24小时助教"而非"代笔者"
- ⚠️ 重要决定（如投稿）应咨询人类导师
