# 金融常用数据库使用指南

## 📊 CSMAR (国泰安经济金融研究数据库)

### 基本信息
- **网址**：http://www.gtarsc.com/
- **覆盖范围**：股票、基金、债券、期货、外汇、经济、行业等
- **高校授权**：大多数985/211院校已购买校园网授权
- **特点**：国内最常用的学术数据库，数据结构化程度高

### 常用子库
| 子库 | 主要内容 | 典型用途 |
|------|---------|---------|
| CSMAR股票系列 | 交易数据、财务报表、公司治理 | 公司金融、资产定价基础研究 |
| CSMAR基金系列 | 基金持仓、业绩、评级 | 机构投资者行为研究 |
| CSMAR债券系列 | 债券发行与交易 | 固收研究 |
| CSMAR衍生品系列 | 期权、期货数据 | 衍生品定价 |
| CSMAR绿色金融 | ESG评分、碳排放 | 可持续金融/ESG研究 |
| CSMAR新闻库 | 新闻文本数据 | 文本分析/NLP研究 |

### 使用技巧
1. **批量下载**：支持按代码/日期范围批量导出
2. **数据字典**：每个字段都有详细说明，务必先阅读
3. **更新频率**：大部分数据T+1更新
4. **Python接口**：`pip install tushare` 或 `akshare` 可部分替代

## 📈 WIND (万得)

### 基本信息
- **网址**：https://www.wind.com.cn/
- **定位**：金融机构终端 + 学术版
- **优势**：实时行情、宏观数据、分析师数据更全
- **注意**：部分功能需单独付费

### 与CSMAR的互补关系
- **用WIND当**：需要实时数据、详细分析师研报、宏观经济高频数据
- **用CSMAR当**：标准化的历史截面/面板数据分析
- **建议**：以CSMAR为主，WIND为补充

## 🔬 CNRDS (中国研究数据服务平台)

### 特色数据（其他数据库没有或不够好的）
- **文本数据**：年报MD&A全文、招股说明书全文、新闻舆情
- **专利数据**：中国专利申请与引用数据
- **特色指数**：各种手工构建的特色指标（如数字化转型指数）
- **ESG数据**：多家机构的ESG评级整合

### 适合的研究方向
- ✅ 文本分析/自然语言处理(NLP)研究
- ✅ 需要独特度量指标的创新性研究
- ✅ 跨学科研究（如法学+金融）

## 🌐 国际数据库

### Compustat (S&P Capital IQ)
- 美国上市公司财务数据，国际对比研究的必备
- 通过WRDS平台访问（多数顶尖高校有授权）

### CRSP
- 美国股市价格和收益率数据
- 与Compustat匹配是资产定价研究的标准配置

### FRED (Federal Reserve Economic Data)
- 美联储经济数据库，免费！
- 宏观金融研究的利器

## 💡 数据使用最佳实践

### 1. 数据获取流程
```
明确需求 → 选择数据库 → 设计查询条件 → 导出原始数据 
→ 变量命名规范化 → 缺失值检查 → 异常值处理 → 描述性统计
```

### 2. 文档记录习惯
- 记录每次数据下载的时间、筛选条件和样本量
- 保存查询条件的截图（方便复现）
- 建立个人"变量词典"统一命名规范

### 3. 常见问题排查
| 问题 | 可能原因 | 解决方法 |
|------|---------|---------|
| 样本量突然减少 | 合并时key不匹配 | 检查ID格式(是否含字母/位数不同) |
| 变量全是缺失 | 字段名变更 | 查看最新数据字典 |
| 数值异常大/小 | 单位问题 | 检查是元还是万元 |
| 时间序列断裂 | 停牌/退市 | 处理ST/*ST样本 |
