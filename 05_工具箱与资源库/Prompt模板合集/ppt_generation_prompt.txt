# 论文PPT生成 Prompt

按照如下要求，解读文章，返回PPT内容，用HTML代码返回，按照经济学PPT的格式完成。

## 核心要求

⚠️ **注意以下要点**：
1. 每页PPT字数不宜过多
2. 每页内字体自适应，保证美观且字不会超过当页内容
3. 表格图像也一定不要超过本页PPT
4. 核心问题的核心词汇加粗
5. 英文返回，用语需要学术专业
6. 所有表格，只需展示最核心的回归系数即可
7. 适当用图表进行展示分析，使得研究逻辑更加完善

## PPT结构模板

### 封面页
- 主标题：论文题目（应简洁、明确）
- 作者，发表时间

### 第1页 研究概要
用3-4个要点浓缩整篇论文的精髓：
- **研究问题**：本文旨在探究……（用一句话说清）
- **核心方法**：采用……（如：构建理论模型，并利用XX数据实证检验）
- **主要发现**：研究发现……（最重要的1-2个结论）

### 第2页：研究背景与现实意义
- 标题：为什么研究这个问题？
- 文字部分：简要描述相关的经济现象、政策变化或现实困境

### 第3页：研究问题与目标
- 明确列出1-3个具体的、可检验的研究问题
- 用一句话总结本研究的目标

### 第二部分：文献与贡献 (第3-5页)
按照文章对文献的综述逻辑，分块总结：
- 内容：不要罗列文献！用表格分类梳理
- 明确指出本文的研究位置（弥补了哪块空白，挑战或补充了哪个观点）

### 第6页：本文的贡献
分点清晰说明：
- **理论贡献**：构建了新的分析框架/引入了新的解释机制
- **实证贡献**：使用了新的数据/识别策略/测度方法
- **视角贡献**：研究了新的情境/结合了新的热点

### 第7页：理论分析框架表或者图
- 展示核心理论模型（简化后的关键公式）或机制传导图

### 第8页：理论分析框架
- 文字精简的总结说明用核心的理论分析框架逻辑

### 第9页：研究假说提出
参考格式：
- 假设1：[变量X]对[变量Y]存在显著的[正向/负向]影响
- 假设2：[机制变量M]在影响路径中起到中介作用
- 假设3：上述影响在[某分组]中更为明显

### 第三部分：实证设计 (第10-14页)

**第10页：模型设定与变量**
- 被解释变量Y，表示……
- 核心解释变量X，表示……，数据来源于……
- 控制变量：包括A、B、C等，以控制……
- 固定效应：个体μ，时间λ

**第11-13页：实证设计**
- 如果方法是简单的计量模型，请给出简要介绍
- 给出核心计量方程
- 如果研究的特色是方法创新，则需要详细介绍实证方法的细节

**第14页：数据来源与描述性统计**
- 数据来源（如：国泰安数据库、CEIC、自行调查）
- 样本范围与处理过程
- 展示描述性统计表

**第15页：识别策略与内生性讨论**
- 重点说明如何解决因果推断的内生性问题
- 使用了什么方法？为什么这个方法可行？

### 第四部分：实证结果 (第13-16页)
- 4.1页: 核心结论
- 4.2页: 内生性或者主要机制
- 4.3页: 异质性分析
- 4.4页: 稳健性分析
- 用一句话解读核心发现

### 第五部分：结论与讨论 (共计两页左右)
- 分点、精炼地总结与假说对应的实证结论
- 讨论：说明研究的缺陷和未来拓展方向

## 使用技巧

1. 将论文PDF上传给AI时，确保清晰度足够
2. 如有公开代码或数据，一并提供可获得更准确的生成结果
3. 生成的HTML可直接在浏览器中打开查看
4. 根据实际汇报时长调整页面数量和详细程度
